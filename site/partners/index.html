Networks and tooling

Integrations, not partnerships: Latheon is deployed on these networks and uses these tools as any developer would.

Networks
  • Latheon test chain, built with Arbitrum Orbit
  • Arbitrum Sepolia (settlement layer and bridge)
  • Ethereum Sepolia (deprecated)
  • Robinhood Chain Testnet (deprecated)
Tokens
  • LTH (our test token)
  • USDG test token on Robinhood Chain Testnet
Verification
  • Router sources on the public testnets verified on Sourcify
  • Blockscout explorer for the test chain

Сети и инструменты

Интеграции, а не партнёрства: Latheon развёрнут в этих сетях и пользуется этими инструментами, как любой разработчик.

Сети
  • Тестовая сеть Latheon на Arbitrum Orbit
  • Arbitrum Sepolia (базовый слой и мост)
  • Ethereum Sepolia (выведена из работы)
  • Robinhood Chain Testnet (выведена из работы)
Токены
  • LTH (наш тестовый токен)
  • Тестовый USDG в Robinhood Chain Testnet
Проверка
  • Исходники роутеров в публичных тестовых сетях подтверждены на Sourcify
  • Обозреватель Blockscout для тестовой сети
LatheonСоло-проект, созданный с помощью ИИ-разработки. Публичный прототип только в тестовых сетях. Тестовые токены ничего не стоят.
