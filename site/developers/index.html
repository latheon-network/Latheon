Circuits and parameters

Groth16 proofs. Proving keys come from a single-operator development setup and are suitable for testnets only.

withdraw_v5

Used by the current V7 pools. Public inputs: root, nullifierHash, recipient, relayer, fee. Every step of the Merkle path is constrained to 0 or 1 (the fix for the pre-V7 flaw). Older pools used withdraw_v3 (V5) and withdraw_v4 (V6).

disclose

Public inputs: commitment, disclosureTag, auditorNonce. Checked by a read-only call to the disclosure verifier.

Pools

Sizes 100 / 50 / 10 / 1. V7: Merkle tree depth 20, up to 1,048,576 deposits per pool, root history 100. Old V5 pools: depth 8, 256 deposits, root history 30.

The JavaScript SDK in sdk/ (0.2.0, not on npm) targets V7: pools and the router from deployments.json, withdraw_v5 proofs, withdrawMany with recipient, relayer and fee; V5/V6 for withdrawals only. It is tested with real proofs on a local EVM and has not yet been run against the test chain. The demo remains the reference.

LatheonSolo project, built with AI-assisted development. Public prototype on testnets only. Test tokens have no value.

Схемы и параметры

Доказательства Groth16. Ключи созданы одной стороной для разработки и подходят только для тестовых сетей.

withdraw_v5

Используется текущими пулами V7. Публичные входы: root, nullifierHash, recipient, relayer, fee. Каждый шаг пути в дереве Меркла ограничен значениями 0 или 1 (исправление ошибки до V7). Старые пулы использовали withdraw_v3 (V5) и withdraw_v4 (V6).

disclose

Публичные входы: commitment, disclosureTag, auditorNonce. Проверяется вызовом верификатора раскрытия только на чтение.

Пулы

Номиналы 100 / 50 / 10 / 1. V7: глубина дерева Меркла 20, до 1 048 576 депозитов в пуле, история корней 100. Старые пулы V5: глубина 8, 256 депозитов, история корней 30.

JavaScript SDK в sdk/ (0.2.0, не в npm) рассчитан на V7: пулы и роутер из deployments.json, доказательства withdraw_v5, withdrawMany с получателем, релейером и комиссией; V5/V6 только для вывода. Проверен с настоящими доказательствами на локальной EVM, против тестовой сети ещё не запускался. Эталоном остаётся демо.

LatheonСоло-проект, созданный с помощью ИИ-разработки. Публичный прототип только в тестовых сетях. Тестовые токены ничего не стоят.

withdraw_v5

用于当前的 V7 资金池。公开输入：root, nullifierHash, recipient, relayer, fee。默克尔路径的每一步都被限制为 0 或 1（修复 V7 之前的缺陷）。旧资金池使用 withdraw_v3（V5）和 withdraw_v4（V6）。

disclose

公开输入：commitment, disclosureTag, auditorNonce. 通过对披露验证合约的只读调用核验。
